# 🧪 Laboratório de JavaScript para QA

> Repositório de estudos práticos — Módulo 2 do curso de Automação com Playwright

## 📌 Sobre este repositório

Este repositório reúne meus exercícios e anotações de estudo de JavaScript, com um objetivo bem claro: **o foco aqui não é virar desenvolvedor**, e sim aprender a dirigir o "volante" da automação de testes.

Playwright, Cypress e qualquer outra ferramenta moderna de automação são construídos sobre JavaScript. Entender a linguagem — mesmo que num nível prático e objetivo — é o que me permite escrever testes mais robustos, entender o que o código está fazendo e resolver problemas com autonomia, em vez de apenas copiar trechos prontos.

Tudo que está aqui é praticado com a mentalidade de quem quer **usar** a linguagem com competência para automatizar testes, não de quem busca dominar toda a teoria de desenvolvimento de software.

## 🗂️ Tópicos em estudo

Estes são os fundamentos que estou praticando ao longo do módulo:

- 📦 **Variáveis** — `let`, `const` e boas práticas de declaração
- 🔤 **Tipos de Dados** — string, number, boolean, null, undefined, etc.
- 📚 **Arrays** — criação, manipulação e principais métodos
- ⚙️ **Funções** — declaração, arrow functions e parâmetros
- 🔀 **Condicionais** — `if/else`, `switch` e operadores lógicos
- 🔁 **Loops** — `for`, `while` e iteração sobre coleções
- ⏳ **Async/Await** — o essencial para lidar com operações assíncronas, peça-chave na automação com Playwright

## 🚀 Estrutura do repositório

À medida que os estudos avançam, os arquivos serão organizados por tópico, permitindo revisitar cada conceito de forma isolada e objetiva.

## 🧭 Mentalidade

> **"Profissional não confia. Profissional confere."**

Essa frase resume a postura que quero levar comigo em cada teste, cada script e cada linha de código: validar, checar e nunca dar nada como certo apenas porque "parece que funcionou".
